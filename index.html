Original-Firmware in deinem Browser. So geht's:

  • SELECT (links) – Icon-Menü durchblättern / Wert ändern
  • CONFIRM (mitte) – bestätigen (z. B. Futter); ohne Menü: Uhr
  • NEXT (rechts) – zurück / abbrechen

Erst die Uhr stellen (CONFIRM durch die Felder), dann schlüpft das Ei (~5 Min). Füttern: SELECT → Napf-Icon → CONFIRM. Dein Stand wird automatisch gespeichert.

Hintergrund

Wähle eine Kulisse – wird gespeichert.
